# Nguyen Viet Bao — GitHub Pages Workspace

This repository hosts a root project hub and a professional portfolio in the `/portfolio` folder.

## Live routes

- Workspace: `https://baonguyen2210ise-bit.github.io/`
- Portfolio: `https://baonguyen2210ise-bit.github.io/portfolio/`

## Structure

```text
/

│   ├── index.html
│   └── assets/

│       ├── js/main.js
```

## Local preview

Run a local server from this repository folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/`.
