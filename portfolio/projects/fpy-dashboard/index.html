06 · Manufacturing Analytics · Quality Performance

First Pass Yield (FPY) Analytics Dashboard

A Power BI analytics solution that converts production test events into actionable FPY, retest, line, model, and machine-code insights for daily quality monitoring.

RoleDashboard Developer & Data Analyst
ScopeProduction Quality · Lines 1300–1399
Project TypeManufacturing Analytics · Quality Monitoring
TechnologyDatabricks SQL · Power BI · DAX · Power Query
STAR Case Study
S

Situation

Production test data contained large volumes of unit- and machine-level events, including repeated transactions and retests. Standard reporting made it difficult to quickly identify which line, model, or machine code was driving FPY loss over a selected period.

T

Task

Build a reliable FPY data model and a filter-responsive dashboard that could move from plant-level performance to the exact line, model, machine group, PC, or machine code requiring attention.

A

Action

Prepared production event data in Databricks, deduplicated test transactions, and derived reporting fields such as Model Code, Family, Machine Group, PC, Line, and Unit ID. Built Power BI measures for first pass, retest, FPY, tested units, and exception rankings, then designed slicers for Date, Family, Model, Machine Group, PC Name, Line, and Machine Code. Added a daily FPY trend, highest/lowest line and model rankings, machine-code retest rankings, and a dynamic date-range-by-line FPY heatmap.

R

Result

Created a single operational view that highlights FPY movement, worst-performing lines and models, and machine codes with abnormal retest behavior. The ranking and heatmap views make recurring quality patterns easier to identify and prioritize for follow-up.
